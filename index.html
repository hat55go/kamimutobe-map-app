      保存先の設定

      記録は GitHub のプライベートリポジトリに保存されます。最初に一度だけ設定してください。

      トークンの作り方
      1. GitHub のトークン作成ページを開く
      2. Token name: 任意（例: kamimutobe-map）
      3. Expiration: 好みの期限（1年など）
      4. Repository access: Only select repositories → kamimutobe-map を選択
      5. Permissions → Repository permissions → Contents を Read and write に
      6. Generate token → 表示された文字列をコピーして上に貼り付け

      トークンはこの端末の中だけに保存され、どこにも送信されません（GitHub 以外）。
